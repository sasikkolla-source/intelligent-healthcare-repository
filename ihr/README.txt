Intelligent Healthcare Repository
=================================
Files:
  index.html  - page structure
  style.css   - styling (light and dark mode)
  script.js   - app logic, data storage, rule-based health screening

How to run:
  Unzip the folder and double-click index.html (Chrome, Edge or Firefox).
  No installation or server needed.

Features:
  - Add and delete patients
  - Vitals tracking and medical records
  - Rule-based screening (BP, heart rate, SpO2, temperature, glucose, BMI, trends)
  - Search across patients, conditions and notes
  - Export data as JSON
  - Data is stored in the browser's local storage

Note: Screening rules are for demonstration only and do not replace clinical judgement.
